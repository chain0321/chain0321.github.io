# 中文朗读

把长篇中文粘贴到页面，点「开始朗读」。页面自动分段，用同一个普通话音色连续朗读，支持暂停、继续和回到开头。

基于 [EasySpeech](https://github.com/leaonline/easy-speech) 2.4.0（MIT）改造。所有 JavaScript 均随源码提供，不依赖外部 CDN、API key、付费接口、服务器或安装步骤。

## 使用

1. 在 Safari、Chrome 或支持 Web Speech API 的浏览器中打开网站。
2. 粘贴中文长文，点「开始朗读」。
3. 暂停后点「继续朗读」，从当前位置附近接着听。无字词边界事件的设备会重读当前短段。

页面自动选择一个普通话音色，优先本机已安装音色。同一次阅读使用相同的音色。音色由操作系统或浏览器提供，不同设备的音质可能不同；本项目没有附带开源神经语音模型。未安装普通话语音时，页面会提示先下载系统语音。

iPhone 建议用 Safari。朗读期间保持页面打开；支持的浏览器会尝试保持屏幕亮起。锁屏、后台运行、电话或其他音频可能中断朗读，不能保证锁屏持续播放。发生中断时点「继续朗读」。本项目目前提供即时朗读，不导出 MP3。

## 长文处理

- 以标点优先切成至多 120 个 Unicode 码点的短段，保留原文字顺序。
- 每次只提交一段语音，结束后开始下一段，避免长文本超过语音引擎限制。
- 在点击事件中同步启动首段，保留 iOS 的用户操作许可。
- 暂停时取消当前语音并记住字词位置；过期回调不会跳过下一段。
- 启动超时或播放异常会保留阅读位置并显示重试提示，不会一直转圈。

## 隐私和费用

无账号、广告、分析脚本、后台服务或应用内收费。网页不保存粘贴的文本，也不会把文本提交给本项目的服务器。系统在线音色可能由浏览器/操作系统将文字交给其语音服务；页面会标明是否采用在线音色。GitHub Pages 的普通网站访问日志由 GitHub 管理。

## GitHub Pages

这是纯静态站点，无需构建。部署目录里的 HTML、CSS、MJS 和 vendor 文件都要保留。

当前仓库布局为 `tts/` 目录。要将这个仓库发布到 GitHub Pages：

1. 打开仓库 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **master**，目录选择 **/ (root)**，保存。
4. GitHub 完成部署后，页面位于 `https://chain0321.github.io/tts/`。

如果使用 GitHub Free，Pages 的源仓库必须公开；私有仓库需要 GitHub 支持的付费方案。改变现有仓库可见性会公开该仓库的文件和历史。也可以将本目录单独复制到一个新的公开仓库，在新仓库启用 Pages，以保持原仓库私有。

上面的地址是启用成功后的目标地址，源码提交本身不代表 Pages 已经开启。源码提交时检查到这个仓库尚未启用 Pages。

## 验证

无需安装依赖，在本目录使用 Node.js 运行：

```sh
npm test
```

测试覆盖长篇中文、无标点文本、emoji、逐字还原、段长限制、中文音色选择、按序连续播放、暂停续读、旧回调竞态、超时恢复以及修改后的 EasySpeech 同步调用。语音引擎使用测试替身；尚未在用户的真实 iPhone 上验证音色、音质和连续播放。
